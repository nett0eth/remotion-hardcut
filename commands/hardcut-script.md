---
description: Write or restructure the hardcut beat sheet (SCRIPT.md)
argument-hint: [topic, or nothing to refine the existing SCRIPT.md]
---

Write the beat sheet for: $ARGUMENTS

Load `hardcut-script` and follow it. The deliverable is `SCRIPT.md` and nothing else — no
scaffolding, no scenes.

If the brief is thin, run `grill-me` first. If it is one line and the user has not thought
it through, grilling is the whole value of this command.

If `SCRIPT.md` already exists and no topic was given, restructure it: re-time every beat
against 0,4s per word, flag beats carrying two ideas, flag consecutive `bigtype` scenes
sharing a `variant`, and cut anything that only exists to fill runtime. Show the beat table
before and after.

Get approval on structure, count and duration before writing the blocks in full.
