# hardcut motion

Reach for a primitive before writing an `interpolate()`. Every one takes `delay` in frames
and reads its curve from `src/design/motion.ts`, which is how fourteen scenes end up feeling
like one video.

## Letter variants — `KineticText`

The six ways type arrives. Pick by word count and by how hard the line should hit.

| Variant | Motion | Use on |
| --- | --- | --- |
| `mask` | Word slides up from behind an invisible edge | Anything over four words. The safe default |
| `pop` | Per-character scale 0.3→1 with overshoot | One or two words. Loud |
| `stretch` | Characters squash on X, then release | One or two words. Mechanical |
| `blur` | Characters arrive at 18px blur and sharpen | After a loud cut — reads as a lens finding focus |
| `scramble` | Characters resolve out of noise | Anything technical |
| `line` | The whole line rises as one block | When the words must not be separable |

`scramble` is deterministic: the glyph comes from a hash of `(index, frame)`, never
`Math.random`, or every render worker would produce different letters. Unresolved slots
still hold a glyph so the line never reflows.

## Camera

`Camera` with a `move` — the shot that separates a promo cut from a screen recording.

| Shot | Zoom | For |
| --- | --- | --- |
| `pushIn` | 1.32 → 1.58 | The default |
| `pullOut` | 1.75 → 1.24 | First shot of a sequence, revealing context |
| `panRight` / `panLeft` | 1.5, ±7% x | Drifting across a wide interface |
| `slam` | 1.1 → 2.0 | A punchline cut. Once per video |
| `breathe` | 1.04 → 1.1 | Keeping an otherwise static shot alive |

Two things to get right or the shot is wasted:

**Easing is linear here and nowhere else in the kit.** A camera that eases in and out reads
as a UI transition, not a camera. Real moves are near-linear across a short shot.

**`FOCUS` decides what the zoom finds.** `center` on a screenshot usually finds empty
backdrop, because interfaces put content on the left. Options: `center`, `left`, `right`,
`top`, `bottom`.

## The rest

| Primitive | Notes |
| --- | --- |
| `FadeIn` | `from: up/down/left/right/none`, `distance`, `blur`. The default entrance |
| `ScalePop` | Things that should feel like they *landed* |
| `Stagger` | Wraps siblings, injects an increasing `delay` |
| `Typewriter` | Deterministic typing with a frame-modulo cursor blink |
| `CountUp` | Tabular figures, so digits don't twitch while counting |
| `DrawPath` | SVG traced like a pen, via `evolvePath` |
| `ClipWipe` | Reveal behind a moving edge. Crisper than a fade for images |
| `Parallax` / `SlowZoom` | Continuous drift and Ken Burns |
| `useEnterExit` | 0→1→0 across a Sequence. Derive a whole scene from it |

| Component | Notes |
| --- | --- |
| `Terminal` | Types commands, spins, resolves, renders inline waveforms |
| `VoiceWave` | Noise-driven audio bars. A *representation* of speech |
| `MicPulse` | Mic glyph with three phase-offset rings |
| `Spinner` | Braille spinner; the frame index picks the glyph |
| `Backdrop` / `FluidBackdrop` | Available, but hardcut runs on flat fields — reach for these only when a scene genuinely needs depth |

`VoiceWave` is not a visualisation of a specific file. When the bars must match real audio,
use `visualizeAudio` from `@remotion/media-utils` instead.

## Third-party runtimes — `src/runtimes/`

GSAP, Anime.js and friends run on their own RAF clock. Remotion has no clock — it mounts a
component and screenshots frame N. A stock `gsap.to()` renders as one frozen frame, or
black. Both adapters fix it the same way: build the timeline **paused**, seek it to the
current frame on every render.

| Adapter | Times in | Reach for it when |
| --- | --- | --- |
| `useGsapTimeline(build, deps)` | seconds | You want GSAP's sequencing grammar — labels, `"-=0.3"`, nested timelines, `elastic` / `back` / `CustomEase` |
| `useGsapProgress(build, p, deps)` | 0–1 | The timeline should stretch to whatever duration the scene gets |
| `useAnimeTimeline(build, deps)` | milliseconds | Anime v4's stagger grammar, or SVG morphing |
| `useMotionSequence(build, deps)` | seconds | Motion's springs, or its `at: "-0.2"` sequence grammar. Smallest of the three |
| `LottieAsset` | — | Anything authored in **Jitter**, LottieLab, or generated by the `text-to-lottie` skill |

Motion has no `autoplay: false`, so its adapter creates the sequence and `pause()`s it in
the same synchronous layout effect before any paint. Its selectors are **global** — always
query from the returned root ref, or two instances of a scene will animate each other's
elements. GSAP's are scoped by `gsap.context`; Anime's and Motion's are not.

### Verifying a runtime still seeks

The `RuntimeCheck` composition animates one bar per library from 0 to 1200px linearly over
two seconds, alongside a frame-driven control bar. Render frames 15 and 45:

```bash
npx remotion still RuntimeCheck out/rt45.png --frame=45 --scale=0.45
```

All four bars must be the same length. If one sits at zero or jumps to full and stays, that
library is running on its own clock again — which is what a version bump breaks, and it
looks exactly like "the animation didn't run". Run it after every runtime upgrade.

**Forbidden inside any adapter:** ScrollTrigger, `gsap.delayedCall`, real-time repeats,
`setTimeout`, `requestAnimationFrame`, CSS transitions, CSS `animation`, Tailwind `animate-*`.
Anything that reads a clock instead of being seeked renders frozen or black.

### Lottie

`text-to-lottie` (`npx skills add diffusionstudio/lottie`) generates Lottie JSON from a
prompt. Drop the result in `public/lottie/` and point a `shot` scene's `lottie` field at it.
Jitter exports the same format via Export → Lottie; its gradients and blurs are the usual
casualties, so check the rendered frame, not the Jitter preview.

### react-bits

Installed as source via `jsrepo`, then ported: delete the RAF loops and progress `useState`,
replace CSS `transition` / `@keyframes` with `interpolate()`, swap `IntersectionObserver` for
a `delay` prop. Keep their layout and CSS — that is the part worth taking.

### Fluid simulations

A WebGL Navier-Stokes sim is stateful, so it tears across Remotion's parallel workers. Use
`FluidBackdrop` (pure function of `frame`) or pre-render the real sim to a video.

## When not to use a primitive

Write a raw `interpolate()` when the motion is specific to one scene and will never repeat.
Follow `remotion-best-practices`: inline the call in the `style` prop, individual transform
properties, clamp both ends, curve from `EASE`.

Write the same raw interpolation twice and it belongs in `src/animation/`.
